### [2026 - Master's Thesis: Detecting Measurable Residual Disease (MRD) in B-cell Acute Lymphoblastic Leukaemia using Convolutional Neural Networks](/MRD_overview/)
Exploration of CellCNN model for MRD Detection in B-cell Acute Lymphoblastic Leukaemia. Several approaches and methodologies have been developed and implemented to address dataset scarcity, patients data contamination and therefore avoid data leakage, and to optimise CellCNN internal data augmentation parameters via Bayesian Optimization (Optuna).

### [2025 - Maze Algorithms](/maze_overview/)
A Python project that compares different maze-generation algorithms in terms of both computational complexity and generation time. The project also includes an empirical analysis of path and solvability complexity, proposing custom metrics and utilising the A* search algorithm as a solving agent.
